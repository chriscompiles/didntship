Fonts are bundled so share images render consistently without system fonts or network requests.

- DejaVu Serif, DejaVu Sans and DejaVu Sans Bold: DejaVu Fonts, original license in LICENSE.txt.
- Noto Emoji: Google, SIL Open Font License in NotoEmoji-LICENSE.txt. Source: https://github.com/google/fonts/blob/main/ofl/notoemoji/NotoEmoji%5Bwght%5D.ttf. Instantiated at weight 400 using fontTools. Emoji render in monochrome to match the cards.
